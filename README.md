# РБПО Лаба3

Гришин Никита, БКС2402, 1бкс24066.

Вариант 6. Репертуар театра и продажа билетов.
Java 17, Spring Boot, база данных H2.

## Данные

Спектакли, залы, показы, пользователи и билеты. У показа есть спектакль и зал, у билета есть показ, место и покупатель. Данные сохраняются в базе.

## Возможности

Для всех сущностей доступны просмотр, создание, изменение и удаление.

1. Бронирование группы соседних свободных мест.
2. Покупка забронированного билета.
3. Возврат купленного билета до начала показа.
4. Отмена показа с отменой билетов и возвратом оплаты.
5. Завершение показа после его окончания с обновлением статусов билетов.
