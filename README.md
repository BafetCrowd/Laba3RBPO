# РБПО Лаба3

Гришин Никита, БКС2402, 1бкс24066.

Вариант 6. Репертуар театра и продажа билетов.

Приложение для учёта спектаклей, показов и билетов. В третьей лабораторной данные перенесены в базу H2 и добавлены операции с бронированием, покупкой и возвратом. Используются Java 17 и Spring Boot.

## Данные

- Спектакль: название, длительность, возрастное ограничение.
- Зал: название и количество мест.
- Показ: спектакль, зал, время начала, цена и статус.
- Пользователь: имя покупателя.
- Билет: показ, место, покупатель, статус, цена покупки и сумма возврата.

У одного спектакля может быть несколько показов. Каждый показ проходит в одном зале, а билет относится к определённому показу и покупателю. Занять одно место двумя действующими билетами нельзя. Связанные записи защищены от удаления.

## Операции

Для всех пяти сущностей доступны просмотр, создание, изменение и удаление через REST API.

1. Бронирование группы соседних мест. Если хотя бы одно место занято, вся бронь отменяется.
2. Покупка забронированного билета. Сохраняется цена на момент покупки, повторно купить билет нельзя.
3. Возврат купленного билета до начала показа. Записывается сумма возврата, место освобождается.
4. Отмена будущего показа. Брони отменяются, для купленных билетов записывается возврат оплаты.
5. Завершение показа после его окончания. Купленные билеты становятся использованными, оставшиеся брони отменяются.

Время проверяется на сервере. Все изменения одной операции сохраняются вместе или откатываются при ошибке. Покупка и возврат учебные, настоящей оплаты нет.

## Запуск и проверка

Открыть проект в IntelliJ IDEA, скопировать `.env.example` в `.env` и указать свои пароли. Запустить класс `Лаба3`. Адрес приложения: `http://localhost:8082`.

Для проверки импортировать `Запросы.postman_collection.json` в Postman и запустить коллекцию по порядку. База сохраняется в папке `данные` после остановки приложения.
